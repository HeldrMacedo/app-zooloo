## 📝 Descrição
Atualmente, a tela de prêmios permite selecionar múltiplos intervalos e valores. No entanto, se o usuário cometer um erro ou desejar começar novamente para aquele palpite, não há uma maneira direta de limpar todas as seleções de uma vez.

## Escopo

- [x] Adicionar um botão "Resetar" na tela de prêmios.
- [x] O botão deve limpar todas as seleções de prêmios para o palpite atual.
- [x] O botão deve ser exibido apenas se houver seleções de prêmios para o palpite atual.
- [x] O botão deve ser exibido apenas se houver pelo menos um intervalo selecionado.
